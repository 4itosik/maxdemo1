## Закономерности

- **Блок 882–891** (10 подряд строк) — пара ошибок «нет `description`» + «нет `type»`. Вероятно, один блок с 10 полями, у каждого отсутствуют оба атрибута.
- **Строки 825, 968, 1004, 1036, 1127, 1333** — также пара ошибок (1 + 2) для одного и того же поля.
- **Ошибки типа 3** (отсутствие `pattern` у `string`) сконцентрированы в диапазоне **996–1319** и не пересекаются с ошибками типов 1/2.
- **Строка 722** — единственная ошибка типа 3 за пределами диапазона 996–1319.
- **Строки 1019, 1120, 1306** — содержат только ошибку типа 1 (`description`), без пары с типом 2.

## Воспроизведение

```bash
python3 scripts/parse_errors.py
```

Скрипт читает `f.html` в корне проекта и выводит ту же группировку в stdout.
