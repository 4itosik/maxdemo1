## `flatten_allof_proto.py`

Прототип расплющивания `allOf`-наследования в `oneOf` + `discriminator`.
Работает по готовому YAML в `tsp-output/`, правки построчные.

```bash
python3 scripts/wip/flatten_allof_proto.py <ИмяБазы> [файл.yaml]
```

Проверено на всех шести дискриминаторных семействах обоих документов.
Семантическая эквивалентность доказана: 58 наследников, 0 расхождений по
свойствам, `required`, `additionalProperties` и описаниям.

Прототипом это остаётся ровно по одной причине: `scripts/compare.py` не умеет
сопоставлять нашу форму `oneOf` + `discriminator` с `allOf`-наследованием
оригинала и после расплющивания выдаёт ~700 ложных расхождений вместо 8.
Сначала нужно доучить сверку — см. промпт задачи.
